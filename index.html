Naturaleza del software

Lo publicado aquí es un software demostrativo: un conjunto de prototipos de interfaz construidos únicamente para representar visualmente el alcance funcional de una futura plataforma. No constituye un producto terminado, comercializable ni apto para uso en producción bajo ninguna circunstancia.

Qué SÍ representa este alcance

  • La estructura y navegación propuesta para tres plataformas: constructora, despacho de arquitectura/inmobiliaria y coworking de bienestar.
  • Los flujos principales de cada plataforma: catálogo público, panel de cliente autenticado y panel administrativo interno.
  • Ejemplos de interacción esperada: filtros, reservas, formularios, notificaciones y mensajería, simulados en el navegador.

Qué NO representa este alcance

  • Ningún dato real: nombres de empresa, personas, obras, proyectos, precios y cifras son ficticios.
  • Ninguna funcionalidad real de backend: no hay base de datos, autenticación real, procesamiento de pagos ni envío de notificaciones o mensajes.
  • El inicio de sesión mostrado en los paneles es simulado a propósito y acepta cualquier credencial; no debe tomarse como referencia de un sistema de seguridad real.
  • Ninguna garantía de que la plataforma final se construya exactamente igual a como aquí se muestra: este es un punto de partida para definir alcance, no una especificación cerrada.
